# Apple Aerial Controller

macOS 原生菜单栏航拍壁纸控制器。自由组合 Apple 航拍分类，定时切换，在桌面完整播放视频后停住。

当前版本：**[v0.1.8](https://github.com/JoeyJia02/apple-aerial-controller/releases/tag/v0.1.8)** · Swift / SwiftUI / AppKit / AVFoundation · [MIT](LICENSE)

## 功能

- 组合自然景观、水下景观、城市景观和地球四类已下载航拍。
- 15 / 30 / 60 / 120 分钟或自定义分钟数轮换；“下一张”立即随机切换。
- “上一张”返回本次运行的切换历史；支持重新播放、暂停播放和从原进度继续。
- 每次切换从头播到视频结尾，再保持最后一帧；新画面就绪后交接，减少灰屏和等待。
- 显示各类资源数量与大小；保存分类、间隔和轮换状态，支持备份及恢复接管前设置。
- 所有操作集中在菜单栏面板，修复“点击壁纸显示桌面”时菜单位置异常。

## 构建和使用

需要 **Apple Silicon、macOS 26、Swift 6** 和本机已下载的 Apple 航拍。目前仅支持**单个内建显示屏**，不自动下载素材。

```sh
bash scripts/build.sh
open build/AerialController.app
```

脚本默认使用 `/usr/bin/swiftc` 和 macOS SDK 26.5。其他工具链可通过 `AERIAL_SWIFTC`、`AERIAL_SDK` 指定，编译器与 SDK 必须兼容。产物为本地 ad hoc 签名应用，尚无正式签名或公证版本。

首次打开保持暂停，选择分类与间隔后点击“开始轮换”。“暂停轮换”保存暂停状态；退出应用保留此前轮换意图，下次打开检查接管状态后重新计时。睡眠、退出或视频播放／暂停期间错过的切换直接跳过，不连续补切。

“上一张”保留本次运行最近 100 条成功切换记录，重启后清空；“下一张”始终从当前分类随机选择。播放暂停与轮换暂停独立，继续播放会重设轮换倒计时；视频进度不跨重启保存。

要登录后继续轮换，将应用固定放在 `/Applications/AerialController.app`，在 **系统设置 → 通用 → 登录项与扩展 → 登录时打开** 中添加它。macOS 负责启动，应用恢复轮换状态，启动时不会立即切图。

## 实现与限制

- **原生切换依赖私有实现**：读取 Apple 本地 manifest 和视频，修改用户 Wallpaper Store 并重载原生服务。首次写入前备份，检测到外部配置变化后停止写入；不关闭 SIP、不修改受保护系统文件。macOS 更新可能使切换失效。
- **桌面播放由应用负责**：公开 AppKit / AVFoundation 播放层位于桌面与图标之间，不接收点击。Apple 负责原生锁屏动画，两者时间线独立，锁屏／解锁可能跳转画面；睡眠、Space 或显示器变化会撤掉播放层。
- 播完后保留尾帧；“返回原生画面”可撤掉播放层。持帧期间未实时监听系统壁纸变更，外部改图后也可用此按钮返回。
- 仅纳入满足当前原生切换校验条件的本地视频，因此“可轮换”可能少于“已下载”。刷新不会下载或删除资源。

## 验证与源码

```sh
bash scripts/check.sh
bash scripts/check-startup.sh
```

检查需要本机 Apple manifest；启动检查还需要 AppKit 图形会话及现有 Wallpaper Store，两者不主动切换壁纸。实机验收环境为 macOS 26.7.1、Swift 6.3.3、SDK 26.5，已确认平滑切换、完整播放、上一张、暂停／继续及显示桌面时的菜单行为。其他系统版本、多屏、全部素材解码和长时运行尚未完整验证。

`Sources/AerialCore/` 包含索引、调度和原生切换；`Sources/AerialController/` 包含菜单界面、偏好设置和桌面播放器；`Tests/` 与 `scripts/` 提供检查及构建入口。
